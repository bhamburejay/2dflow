\section{Outline:}
\begin{itemize}
    \item 4-Position: $x^{\mu} = (t,0,0,z)$
    \item Proper time: $\tau = \sqrt{t^2 - z^2}$
    \item Spacetime rapidity: $\eta_{s} = y = \frac{1}{2}\ln\left(\frac{t+z}{t-z}\right)$
    \item Four-velocity: $u^\mu = \frac{x^\mu}{\tau} = \left(\frac{t}{\tau}, 0, 0, \frac{z}{\tau}\right)$
\end{itemize}

Equation (21) from Bjorken's paper with $\eta_{\mu\nu}=(+---)$:
\begin{equation}
    \frac{d\epsilon}{d\tau} = -\frac{(\epsilon + p)}{\tau}
\end{equation}

This equation describes the rate of change of the energy density $\epsilon$ with respect to the proper time $\tau = \sqrt{t^2 - z^2}$ in a one-dimensional hydrodynamic expansion. Here, $p$ is the pressure, and $z$ is the longitudinal coordinate (beam direction).

\subsection{Hydro Equations and Energy-Momentum Tensor:}
The starting point is the energy-momentum tensor \(T_{\mu\nu}\) for a perfect fluid, which is given by:
\begin{equation}
    T^{\mu\nu} = (\epsilon + p) u^\mu u^\nu + \eta^{\mu\nu} p
\end{equation}
where $u_\mu u^\mu = 1$. The conservation of energy and momentum is expressed by the EOM:
\begin{equation}
    \partial_\mu T^{\mu\nu} = 0
\end{equation}
This is the relativistic generalization of the continuity equation and Euler's equation in fluid dynamics.

\subsection{Assumption of Boost Invariance:}
\textit{Main assumption} is that the system is boost-invariant in the longitudinal direction. This means that the system looks the same in all frames related by a Lorentz boost along the beam axis (the $z$-axis). As a result, the energy density $\epsilon$, pressure $p$, and temperature $T$ depend only on the proper time $\tau = \sqrt{t^2 - z^2}$, and not on rapidity $y = \frac{1}{2} \ln \left( \frac{t + z}{t - z} \right)$, hence,
\[
\epsilon = \epsilon(\tau), \quad p = p(\tau), \quad T = T(\tau)
\]

\subsection{Four-Velocity in Boost-Invariant Flow:}
In a boost-invariant system, the four-velocity \(u_\mu\) of the fluid is given by:
\begin{equation}
\label{u}
    u^\mu \equiv \frac{dx^{\mu}}{d\tau} = \left(\frac{dt}{d\tau},0,0,\frac{dz}{d\tau}\right)=  \left(\frac{t}{\tau},0,0,\frac{z}{\tau}\right)=\frac{x^\mu}{\tau}    
\end{equation}

\subsection{Energy-Momentum Conservation in Boost-Invariant System:}
The conservation of energy and momentum ($\partial_\mu T^{\mu\nu} = 0$) can be simplified using the boost-invariant assumption. For the \(\nu = 0\) component (energy conservation), we have:
\begin{eqnarray}
    \partial_\mu T^{\mu 0} = 0 \\
    \partial_\mu\left[(\epsilon + p)u^\mu u^0 - \eta^{\mu 0}p\right] = 0
\end{eqnarray}
Using equation \eqref{u}
\begin{eqnarray}
    \partial_\mu\left[(\epsilon + p)\frac{x^\mu t}{\tau^2}\right] - \partial_0 p &=& 0 \\
    \frac{d(\epsilon + p)}{d\tau}\frac{x_\mu}{\tau}\cdot\frac{x^\mu t}{\tau^2} + (\epsilon + p)\partial_\mu\left(\frac{x^\mu t}{\tau^2}\right) -\frac{dp}{d\tau}\frac{t}{\tau} &=& 0
\end{eqnarray}
Simplify using $x^\mu x_\mu = \tau^2$
\begin{eqnarray}
    \frac{d(\epsilon + p)}{d\tau}\frac{t}{\tau} + (\epsilon + p)\left(\frac{3t}{\tau^2} - \frac{2t}{\tau^2}\right)  = 0
\end{eqnarray}

\begin{eqnarray}
    \frac{d\epsilon}{d\tau} + \frac{\epsilon + p}{\tau} = 0
\end{eqnarray}
This is the key equation that describes how the energy density \(\epsilon\) of quark-gluon plasma changes with proper time $\tau$.

\subsection{Physical Interpretation:}
\begin{enumerate}
    \item The term $\frac{d\epsilon}{d\tau}$ represents the rate of change of energy density with proper time.
    \item The term $\frac{\epsilon + p}{\tau}$ represents the work done by the fluid as it expands. The negative sign indicates that the energy density decreases as the system expands.
    \item The  $\frac{1}{\tau}$ factor arises because of boost-invariant one-dimensional expansion.
\end{enumerate}

\subsection{Summary:}
Equation (21) is derived from the conservation of energy and momentum in a boost-invariant hydrodynamic system. The key assumptions are,
\begin{enumerate}
    \item The system is boost-invariant, so $\epsilon$, $p$, and $T$ depend only on $\tau$.
    \item The energy-momentum tensor is that of a perfect fluid.
    \item The four-velocity of the fluid is given by $u_\mu = \frac{x_\mu}{\tau}$. 
\end{enumerate}
This equation governs the evolution of the energy density in the expanding quark-gluon plasma.

\section{Main Ideas: Coding}
The main objective of the vischydro.cpp code is to simulate the evolution of a hydrodynamic system using ideal hydrodynamics. The code uses PETSc (Portable, Extensible Toolkit for Scientific Computation) to handle parallel computations and solve the hydrodynamic equations over time.

Key Components and Their Roles:
\subsection{Equation of State (EOS) Class:}
The \textbf{\textit{EOS}} class provides methods to calculate various thermodynamic properties such as pressure, temperature, and speed of sound squared based on the energy density and baryon density.

\subsection{VischydroNode Structure:}
The \textit{\textbf{VischydroNode}} structure represents a cell in the hydrodynamic simulation. It contains properties like energy, momentum, pressure, and velocity.

\subsection{Hydrodynamic Functions:}
\textit{\textbf{FillVischydroNode}}: Initializes a \textit{\textbf{VischydroNode}} with values from the \textit{\textbf{EOS}}.
\textbf{\textit{idealHydroCellIFunction}} and \textbf{\textit{idealHydroCellIFunctionDerivative}}: Functions used to check consistency and calculate derivatives for the Newton-Raphson method.
\textbf{\textit{idealHydroCellSolve}}: Uses the Newton-Raphson method to solve for the energy density in a hydrodynamic cell.

\subsection{Vischydro Class:}
The Vischydro class manages the hydrodynamic simulation. It sets up the computational domain, initializes the solution vector, and handles time-stepping using PETSc's TS (time-stepping) routines. It reads initial conditions from an HDF5 file, sets up the time-stepping parameters, and advances the solution in time.

\subsection{PETSc Integration:}
The code uses PETSc to handle parallel computations, solve differential equations, and manage data. Functions like \textbf{\textit{EulerRHSFunction}}, \textbf{\textit{LHSIFunction}}, and \textbf{\textit{LHSIJacobian}} define the right-hand side, implicit function, and Jacobian for the time-stepping solver.

\subsection{Main Function:}
The main function initializes PETSc, reads input parameters from a JSON file, sets up the Vischydro object, and advances the solution in time using \textbf{\textit{TSSolve}}. It also handles writing the solution to an HDF5 file at each time step.

\subsection{Inputs and Outputs:}
\textbf{Inputs}: JSON configuration file (inputs.json or specified via command line) containing parameters like grid size, initial time, CFL condition, and final time. HDF5 file containing initial conditions for the hydrodynamic variables.

\textbf{Outputs}: HDF5 file containing the solution at each time step and the final solution.

\subsection{Summary:}
The vischydro.cpp code simulates the evolution of a hydrodynamic system using ideal hydrodynamics. It uses PETSc to handle parallel computations and solve the hydrodynamic equations over time. The main steps include reading input parameters, initializing the computational domain and solution vectors, advancing the solution in time using PETSc's time-stepping routines, and writing the solution to an HDF5 file.
